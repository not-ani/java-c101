# 2-2 Exercises

These files are from Section 2-2, **What Is My Program Doing?**

## Text01.java — Statements and whitespace

`Text01` prints a cat. This show that Java executes complete statements, which end with semicolons, isntead of executing one source-code line at a time

## Text02.java — Braces and indentation

`Text02` shows how matching braces and consistent indentation organize a Java program. The repaired program prints the numbers 1 through 4, with each number on its own line

## Text03.java — `main` and method calls

`Text03` demonstrates that Java begins execution in the `main` method. The `drawLegs()` method contains the code for the cat's legs, and calling `drawLegs();` from `main` makes that code run after the cat's face is printed

## Run the programs

From this directory, compile and run any file. For example:

```bash
javac Text03.java
java Text03
```
